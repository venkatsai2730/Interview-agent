# Senior Backend Engineer — Distributed Systems
**Company:** TechScale India Pvt Ltd
**Location:** Bangalore, India (Hybrid)
**Experience:** 5-8 years

---

## About the Role
We're looking for a Senior Backend Engineer to join our Platform team. You'll design and build the core distributed systems that power our real-time data processing platform serving 500+ enterprise customers. This is a high-impact role where you'll work on systems handling 10M+ events per second with sub-100ms latency requirements.

---

## What You'll Do
- Design and implement distributed data pipelines processing 10M+ events/second
- Build highly available services with 99.99% uptime SLA
- Lead architecture decisions for new platform features
- Implement event-driven microservices using Kafka and gRPC
- Design systems for horizontal scalability across multiple regions
- Conduct code reviews and mentor engineers on distributed systems patterns
- Drive observability and reliability improvements across the platform
- Collaborate with Product and Data Science teams on real-time ML feature serving

---

## Must-Have Requirements
- 5+ years of backend engineering experience
- Strong experience with distributed systems (event sourcing, CQRS, saga patterns)
- Proficiency in Go or Rust (Python acceptable if willing to learn Go)
- Deep experience with Apache Kafka or similar event streaming platforms
- Experience designing systems for horizontal scale (10K+ requests/sec)
- Strong understanding of database internals (partitioning, replication, consensus)
- Experience with Kubernetes and container orchestration in production
- Track record of owning and operating services with strict SLA requirements
